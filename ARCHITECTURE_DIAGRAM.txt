================================================================================
DATA FLOW
================================================================================

USER CHANGES SETTING:
  UI Widget changed → KisPrintDialog::slotXxxChanged()
                   → KisPrintSettings updated
                   → settingsChanged() signal
                   → KisPrintPreviewWidget::updatePreview()
                   → Widget repainted

USER CLICKS PRINT:
  OK button → KisPrintDialog::slotPrint()
           → updateSettings() (UI → Settings)
           → KisPrintEngine::print(image, settings, printer)
           → renderPage() → drawPrintMarks()
           → QPrinter outputs to printer/PDF
           → settings->saveSettings() (KConfig)

SETTINGS PERSISTENCE:
  On dialog open:  KisPrintSettings::loadSettings() from KConfig
  On print:        KisPrintSettings::saveSettings() to KConfig
  Config group:    "PrintDialog" in kritarc

================================================================================
COLOR MANAGEMENT FLOW
================================================================================

  KisImage (source color space)
      ↓
  KoColorSpace::profile() → Source profile displayed
      ↓
  User selects printer profile + rendering intent
      ↓
  KisPrintEngine::convertColorSpace()
      ↓
  KoColorConversionTransformation applied
      ↓
  QImage with printer color space
      ↓
  QPainter draws to QPrinter

================================================================================
KEY INTEGRATION POINTS
================================================================================

1. Krita Action System:
   kritamenu.action → KisActionManager → KisMainWindow
   
2. Color Management:
   KisImage → KoColorSpace → KoColorProfile → LCMS2
   
3. UI Framework:
   Qt Designer (.ui) → ki18n_wrap_ui → Wdg class → KoDialog
   
4. Settings:
   KSharedConfig → KConfigGroup → KisPrintSettings
   
5. Printing:
   Qt PrintSupport → QPrinter → Platform print system

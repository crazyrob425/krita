COMPREHENSIVE PRINT DIALOG FOR KRITA - FEATURE IMPLEMENTATION

================================================================================
WHAT WAS DELIVERED
================================================================================

1. CORE INFRASTRUCTURE (4 new classes, ~2,100 lines of code)
   
   ✅ KisPrintSettings - Centralized settings data model
      - Printer configuration (name, page size, orientation, copies)
      - Layout settings (position, scaling, margins)
      - Color management (profiles, intent, BPC)
      - Print marks and adjustments
      - KConfig persistence
   
   ✅ KisPrintDialog - Main dialog with tabbed UI
      - Basic tab: printer, page setup, layout, margins
      - Color Management tab: profiles, rendering intent
      - Advanced tab: print marks, image adjustments
      - Real-time preview integration
   
   ✅ KisPrintPreviewWidget - Live print preview
      - Visual page boundaries and margins
      - Zoom controls (Fit, 100%)
      - Real-time updates when settings change
   
   ✅ KisPrintEngine - Print backend
      - QPrinter integration
      - Color management transforms
      - Print marks generation (crop, registration, color bars)
      - High-resolution rendering

2. USER INTERFACE

   ✅ Professional 3-tab layout
      Tab 1 (Basic):
        - Printer selection dropdown
        - Page size: A4, Letter, Legal, A3, A5
        - Orientation: Portrait/Landscape
        - Copies with collation
        - Position: Center/Top-Left/Custom
        - Scaling: Fit to page/Percentage/Specific dimensions
        - Aspect ratio lock
        - Margins (mm): Top, Bottom, Left, Right
      
      Tab 2 (Color Management):
        - Source profile display (from document)
        - Printer profile selection
        - Rendering intent: Perceptual/Relative/Absolute/Saturation
        - Black point compensation toggle
        - Proof colors option
      
      Tab 3 (Advanced):
        - Print marks: Crop/Registration/Color bars/Page info
        - Image adjustments: Brightness/Contrast/Saturation
        - Background color handling

   ✅ Live Preview Panel
      - Shows image on page with margins
      - Zoom controls
      - Updates in real-time

3. MENU INTEGRATION

   ✅ File → Print menu item (Ctrl+P)
   ✅ Action registered in kritamenu.action
   ✅ Menu item enabled in krita5.xmlgui
   ✅ Handler in KisMainWindow::slotPrintFile()

4. SETTINGS PERSISTENCE

   ✅ All settings saved to ~/.config/kritarc
   ✅ Restored on next print operation
   ✅ Uses KConfig/KConfigGroup

5. COLOR MANAGEMENT INTEGRATION

   ✅ Uses existing KoColorSpace/KoColorProfile
   ✅ Rendering intent support
   ✅ Black point compensation
   ✅ Source profile detection from image
